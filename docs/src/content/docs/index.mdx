`rriscripts` is three independent toolkits in one repository. Each one is useful
on its own, and you can install just the part you need.

## Which one do I want?

| If you want to… | Use |
|---|---|
| Run one command on a compute node | [`qexec.sh`](qexec/workflows/#run-one-batch-command) |
| Get an interactive session | [`qexec.sh --interactive`](qexec/workflows/#start-an-interactive-session) |
| Run a parameter sweep | [`batch_exec.sh`](qexec/workflows/#generate-and-submit-a-command-grid) |
| Submit a file of commands you already have | [`bexec.sh`](qexec/workflows/#batch-a-command-file-across-several-array-tasks) |
| Watch what a running job is actually doing | [`rjobtop.py`](qexec/monitoring/) |
| Preprocess a BIDS dataset with fMRIPrep | [`fmriprep_launcher.py`](fmriprep/workflow/) |
| Re-run only the subjects that failed | [`rerun-failed`](fmriprep/subcommands/#rerun-failed--retry-only-the-failed-subjects) |
| Pull data out of an XNAT server | [`xnat_cli.R`](xnat-cli/downloading/) |

## Requirements at a glance

Requirements depend on which part you use.

- **qexec** — Bash 3.2+, Python 3.7+, SLURM, and GNU Parallel for packed and
  batched command-file execution. Tcl/Tk only for the optional GUI frontends.
- **fmriprep** — Python 3.10+, SLURM, and Singularity/Apptainer or Docker.
- **xnat_cli** — R with `optparse` and `xnatR`.
